*Cliente - Servidor

-Conceito e definição: O estilo Cliente e Servidor consiste em separar a visualização do sistema de toda a logica e funcionamento, Nesse estilo, o servidor separado contem toda a logica e o cliente faz requisições HTTP para acessar esse servidor

-Casos de uso comuns: 

    --Jogos online: Um servidor coordena as interações dos jogadores distribuindo as interações para os clientes

    --Aplicações Web: Um browser faz requisições ao servidor para ter acesso aos dados

-Principais vantagens: Escalavel, centralizado e reduz carga do cliente

-Principais desvantagens: dependencia no servidor unificado, propenso a quedas de sistema, latencia pode impactar tempo de respostas
